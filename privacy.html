ガレキ積み帳プライバシーポリシー

制定日：2026年11月3日

ガレキ積み帳（以下「本アプリ」）の作者（GitHub：creat4ro、以下「作者」）は、利用者の情報を次のとおり取り扱います。本アプリは作者のサーバーを持たず、作者が利用者のデータを受け取ったり見たりすることはありません。

1. 本アプリが扱う情報

  • 利用者が入力したキットの情報（キット名、ディーラー、原型師、購入日、価格、保管場所、メモ、工程の記録など）
  • 利用者が追加した写真（取り込み時に縮小して保存し、撮影場所などの位置情報は含めません）
  • Googleドライブで同期する場合：Googleアカウントのメールアドレス（どのアカウントで同期しているかを画面に表示するためだけに使います）

2. 情報の保存場所

  • 利用者の端末：入力した情報と写真は、利用者の端末のブラウザ内（IndexedDB）に保存されます。
  • 利用者のGoogleドライブ（同期を使う場合のみ）：利用者自身のGoogleドライブに本アプリが作る「ガレキ積み帳」フォルダに、キットの情報（kits.json）と写真が保存されます。

作者や第三者のサーバーに、これらの情報が送られることはありません。

3. Googleのユーザーデータの取り扱い

本アプリは、Googleアカウントでのログイン時に次の権限を求めます。

  • Googleドライブのファイル（drive.file）：本アプリが作成したフォルダとファイルの作成・読み込み・更新・削除にのみ使います。本アプリが作成していないドライブ上のファイルにはアクセスできません。
  • メールアドレス（openid、email）：同期中のアカウントを画面に表示するためにのみ使います。

Googleから受け取るアクセストークンは、アプリを開いている間だけ端末のメモリ上で使い、保存しません。Googleから受け取った情報を、広告、分析、販売、そのほか同期以外の目的に使うことはなく、第三者に提供することもありません。人がその内容を読むこともありません。

本アプリによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に準拠します。

4. 外部サービスとの通信

本アプリを表示・利用するとき、次のサービスと通信します。これらのサービスは、通信の際に利用者のIPアドレスなどを受け取ることがあり、それぞれの方針に従って取り扱われます。

  • GitHub Pages（本アプリのファイルの配信）
  • Google Fonts（画面に使う文字の配信）
  • Googleのログイン機能とGoogle Drive API（同期を使う場合）

本アプリは、アクセス解析、広告、Cookieによる追跡を行いません。

5. 情報の削除と連携の解除

  • キットは、アプリの詳細画面の「このキットを削除」で削除できます。同期中は、ドライブ上のデータからも削除されます。
  • 「ログアウトしてこの端末のデータを消す」で、その端末に保存された情報をすべて消せます。
  • Googleドライブ上のデータは、ドライブの「ガレキ積み帳」フォルダを削除すると消せます。
  • 本アプリとGoogleアカウントの連携は、Googleアカウントの「サードパーティ製のアプリとサービス」からいつでも解除できます。

6. 安全のための取り組み

本アプリは、ドライブへのアクセス権限を本アプリが作成したファイルだけに限り、読み込めるプログラムを本アプリ自身とGoogleのログイン機能に制限しています。端末内のデータは端末のロックで、ドライブ上のデータはGoogleアカウントの保護で守られます。Googleアカウントの2段階認証を有効にすることをおすすめします。

7. このポリシーの変更

本ポリシーを変更する場合は、このページで内容と変更日をお知らせします。

8. お問い合わせ

本ポリシーや本アプリについてのお問い合わせは、GitHubのIssuesからお願いします。

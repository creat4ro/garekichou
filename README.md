# ガレキ積み帳

積んでいるガレージキットを、写真付きで管理するアプリです。

**アプリを開く:https://creat4ro.github.io/garekichou/**

- キットを写真付きで登録し、未開封から完成までの工程を記録
- 工程を進めた日付を自動で記録
- スマホとPCのどちらでも使え、ホーム画面に追加すればオフラインでも動作
- Googleドライブで、同じアカウントの端末どうしを同期(任意)

データは利用者の端末と、同期を使う場合は利用者自身のGoogleドライブにだけ保存されます。

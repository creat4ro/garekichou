# ガレキ積み帳(スマホ単体版)

キット情報と写真はすべてスマホのブラウザ内に保存されます。サーバーやClaudeには送られません。
iPhone(Safari)とAndroid(Chrome)のどちらでも動きます。

## ファイル

- `index.html` … アプリ本体
- `manifest.webmanifest` … ホーム画面に追加したときの名前・アイコン
- `sw.js` … オフラインで動かすための仕組み
- `icon-180.png` / `icon-192.png` / `icon-512.png` … アイコン

## 公開する(GitHub Pages・無料、1回だけ)

1. https://github.com でアカウントを作る
2. 右上の「+」→「New repository」。名前は `garekichou` など、Public を選んで作成
3. 「uploading an existing file」を押し、このフォルダのファイルを全部ドラッグして「Commit changes」
4. リポジトリの「Settings」→「Pages」→ Branch を `main` / `(root)` にして Save
5. 1〜2分後、`https://ユーザー名.github.io/garekichou/` で開けるようになります

公開されるのは画面のファイルだけです。登録したキットや写真は各自のスマホの中にしか保存されないので、URLを他人が開いても中身は見えません。

## ホーム画面に追加する

- **iPhone**:Safariで開く → 共有ボタン → 「ホーム画面に追加」
- **Android**:Chromeで開く → 右上の「︙」→ 「ホーム画面に追加」(または「アプリをインストール」)

ホーム画面から起動すると、アプリのように全画面で動き、電波がなくても使えます。
iPhoneはホーム画面に追加しておかないと、しばらく開かなかったときにデータが消されることがあるので、必ず追加してください。

## 機種変更・バックアップ

1. 前のスマホで右上の「バックアップ」→「バックアップファイルを作る」
   - iPhone:共有画面で「"ファイル"に保存」を選び、iCloud Driveなどへ
   - Android:ダウンロードフォルダに保存されます。Googleドライブにも上げておくと安心
2. 新しいスマホでアプリを開いてホーム画面に追加
3. 「バックアップ」→「ファイルを選んで読み込む」でそのファイルを選ぶ

iPhone ⇔ Android の間でも同じファイルで移せます。月に1回くらいバックアップしておくと安心です(30日以上たつと一覧に案内が出ます)。

## 画面を更新したとき

`index.html` を書き換えてアップロードし直したら、`sw.js` の `VERSION = "v1"` を `"v2"` のように上げてから一緒にアップロードしてください。次にアプリを開いたとき新しい版に切り替わります(データはそのまま残ります)。
